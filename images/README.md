# 배포 주소 QR 코드

할망 길동무 웹사이트(Vercel 배포 주소)로 연결되는 QR 코드입니다.

| 항목 | 내용 |
|---|---|
| 연결 주소 | https://halmang-gildongmu.vercel.app |
| 파일 | [`qr.png`](qr.png) |
| 형식 / 크기 | PNG, 600 × 600 px |
| 디자인 | 흰색 배경 + 검은색 QR 코드 (여백 2칸) |
| 생성 방식 | 기존 이미지를 복사하지 않고 위 주소로 새로 생성 |

![배포 주소 QR 코드](qr.png)

## 확인한 내용

- 만든 PNG를 QR 디코더(`jsqr`)로 읽으면 `https://halmang-gildongmu.vercel.app` 이 그대로 나옵니다.
- 해당 주소에 접속하면 정상 응답(HTTP 200)이 옵니다.
- 실제 휴대폰 카메라로 스캔한 확인은 하지 않았습니다. 인쇄물에 쓰기 전에 한 번 스캔해 보세요.

## 다시 만들기

배포 주소가 바뀌면 프로젝트 폴더에서 아래 명령으로 새로 만듭니다. (설치 없이 실행됩니다)

```bash
npx --yes qrcode -o images/qr.png -w 600 -m 2 -d 000000 -l FFFFFF "https://새-배포-주소"
```

| 옵션 | 뜻 |
|---|---|
| `-o` | 저장 위치 |
| `-w 600` | 가로·세로 600px |
| `-m 2` | 바깥 여백 2칸 |
| `-d 000000` | 어두운 칸 색 (검정) |
| `-l FFFFFF` | 밝은 칸 색 (흰색) |

## 사용 팁

- 인쇄할 때는 가로·세로 2cm 이상으로, 배경과 글자색 대비를 유지하세요.
- 이 폴더의 파일은 웹사이트 화면에 쓰이지 않아 Vercel 배포에는 영향이 없습니다.
